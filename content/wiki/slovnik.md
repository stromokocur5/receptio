## Na panvici a v hrnci

| Slovo                         | Čo urobiť                                                                           |
| ----------------------------- | ----------------------------------------------------------------------------------- |
| **speniť, zosklovatiť**       | cibuľu na oleji 3–5 min na strednom ohni, kým nezmäkne a nie je priesvitná          |
| **opiecť dozlatista**         | na rozpálenom oleji, kým nie je zlatohnedé – nemiešaj stále, nechaj to chytiť farbu |
| **orestovať, opražiť**        | krátko na vysokom ohni za stáleho miešania (cesnak, korenie – 30 sekúnd až minúta)  |
| **dusiť, podusiť**            | pod pokrievkou na miernom ohni s trochou tekutiny                                   |
| **variť**                     | vo vriacej vode alebo omáčke, bublá                                                 |
| **zovrieť, priviesť do varu** | zohriať, kým to nezačne bublať, potom zvyčajne stiahnuť oheň                        |
| **povariť, prevariť**         | krátko nechať bublať, 1–5 minút                                                     |
| **variť na miernom ohni**     | len jemne bublinky pri okraji, nie divoký var                                       |
| **zredukovať**                | variť bez pokrievky, kým sa tekutina neodparí a omáčka nezhustne                    |
| **odstaviť**                  | vziať z ohňa (napr. pred pridaním papriky, aby nezhorkla)                           |
| **dotiahnuť**                 | nechať po vypnutí ohňa ešte chvíľu pod pokrievkou                                   |
| **zápražka**                  | múka opražená na oleji, ktorou sa zahusťuje – [viac](/wiki/zahustovanie)            |

## Príprava

| Slovo                   | Čo urobiť                                                                          |
| ----------------------- | ---------------------------------------------------------------------------------- |
| **scediť**              | vyliať cez sitko, tekutina odtečie                                                 |
| **prepláchnuť**         | premyť v sitku pod studenou vodou (ryža, strukoviny)                               |
| **namočiť**             | nechať vo vode (strukoviny cez noc, kešu 15 minút v horúcej)                       |
| **blanšírovať, spariť** | na chvíľku do vriacej vody a hneď do studenej – zelenina ostane zelená a chrumkavá |
| **vyžmýkať**            | vytlačiť vodu (tofu, strúhanú cuketu) cez utierku                                  |
| **prelisovať**          | pretlačiť cesnak cez lis                                                           |
| **nastrúhať**           | na strúhadle, jemne alebo nahrubo                                                  |
| **rozmixovať dohladka** | kým nie sú hrudky                                                                  |
| **vyšľahať**            | rýchlo miešať metličkou, aby sa spojilo alebo zväčšilo objem                       |
| **zapracovať, vmiešať** | jemne premiešať, nie šľahať                                                        |
| **dochutiť**            | ochutnať a pridať soľ, kyselinu, korenie podľa seba – [ako](/wiki/dochucovanie)    |

## V rúre

| Slovo                        | Čo urobiť                                                              |
| ---------------------------- | ---------------------------------------------------------------------- |
| **predhriať**                | zapnúť rúru 10–15 minút vopred, aby mala teplotu, keď tam jedlo vložíš |
| **piecť**                    | v rúre, suché teplo                                                    |
| **zapiecť**                  | krátko piecť navrchu, kým povrch nezhnedne                             |
| **dozlatista / dochrumkava** | kým nie je povrch zlatý a pevný                                        |

## Množstvá

- **štipka** – čo chytíš medzi palec a dva prsty (asi 0,5 g)
- **podľa chuti** – začni málom, ochutnaj, pridaj
- **PL, ČL, hrnček** – [odmerky](/wiki/jednotky)
